# Security Policy

AV Upgrade is currently an unaudited research prototype and must not secure
production funds.

Please do not open a public issue for a suspected vulnerability that could put
an existing integration at risk. Use GitHub's private vulnerability reporting
for this repository and include:

- affected contract and function;
- impact and attack assumptions;
- minimal reproduction or failing test;
- suggested mitigation, if known.

No bug bounty is currently offered. Coordinated disclosure and clear technical
reports will be credited with the reporter's permission.
